# tools

## Requirements

- working Go tooling
  - install from: https://go.dev/dl/
    
## Install

- checkout this repo
- cd into top level directory
- The following should install to your default Go bin directory (platform dependent)
  - If on linux or macosx:
    - make instdrpt
  - If on windows (not tested) 
   - go install cmd/drpt/drpt.go
- Assuming your Go bin directory is on your executable path:
  - Follow help by invoking:
    - drpt -help

## Configuring
There are two configuration files consulted.  See help messaging for details.
