# tools
Install all tools with:

`go install github.com/larryr/tools/cmd/...@latest`

## gopuml
generate PlantUML diagram for a set of go files.

## modgrphviz
generate Grapghviz DOT language from `go mod graph` output

## mkdoc
convert a Markdown file to a standalone HTML document or a PDF
(portrait by default, landscape with `-l`). Pure Go; no external
binaries. See [docs/mkdoc.md](./docs/mkdoc.md) for the design.
